# Changelog

## 1.1.1 — 2026-11-08

- Replace download-only page with a responsive QR toolkit and localized pages.
- Add website/text/Wi-Fi/email QR generation; PNG and SVG exports.
- Add image upload/paste/drop scanning to the website and extension.
- Add dark/light/system themes and automatic/manual language selection.
- Add explicit active-tab screenshot scanning to the extension.
- Add cached version checks that display an upgrade notice only for newer releases.
- Add Chromium and Firefox packaging, release metadata and SHA-256 checksums.
- Add shared brand assets, PNG/SVG promotional artwork, favicon set.
- Add installation, about, privacy, sitemap, canonical/hreflang and social metadata.
- Keep all QR processing local; validate links and never automatically open decoded URLs.
- Add documentation, MIT license, security policy and reproducible release checks.

## 1.1.0 — existing baseline

Existing source manifest inside the legacy `QR-Scanner-v1.zip` is 1.1.0.
The original archive is retained for compatibility. Historical release date
and store publication status have not been independently established.
