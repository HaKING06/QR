Install QR Scanner

  1. Extract the downloaded ZIP into a permanent folder.
  2. Open chrome://extensions (Edge: edge://extensions) and enable Developer mode.
  3. Choose Load unpacked and select the extracted folder containing manifest.json.

Keep this folder. For updates, replace its files with the newer package and click Reload. Firefox: about:debugging → This Firefox → Load Temporary Add-on → manifest.json (temporary until restart). Safari needs Xcode conversion, signing and a separate distribution process.
