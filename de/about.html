Über uns

QR Scanner ist ein Open-Source-Projekt von HaKING (Halit). Es macht alltägliche QR-Aufgaben schnell, zugänglich und datensparsam. Erstelle QR-Codes für Webseiten, Texte, WLAN und E-Mails oder lies einen Code aus einem Bild.

Datenschutz von Anfang an

QR-Inhalte werden niemals an unsere Server gesendet. Keine Analyse, Tracking-Cookies oder QR-Verläufe. Design- und Spracheinstellungen bleiben auf deinem Gerät. Hosting-Anbieter können übliche Verbindungsprotokolle verarbeiten.
