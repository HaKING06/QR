Mes codes QR expirent-ils ?

Les codes QR statiques n’expirent pas. Le site web de destination doit rester accessible.

Mes fichiers sont-ils envoyés en ligne ?

Non. Les images, textes et mots de passe Wi-Fi sont traités localement. Seule la vérification des mises à jour de l’extension contacte qr.haking.tr.

Puis-je personnaliser mon code QR ?

Choisissez la couleur et la taille d’exportation. Les fichiers PNG et SVG incluent une marge blanche de quatre modules pour une lecture fiable.

Quels navigateurs sont compatibles ?

Utilisez le site dans un navigateur récent. Des versions officielles sont disponibles dans les boutiques Chrome et Edge. Les ZIP Chromium s’installent manuellement. Firefox exige une signature pour une installation permanente ; Safari utilise actuellement les outils web.
