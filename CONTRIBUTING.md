# Contributing

Open an issue describing the concrete problem and browser version. Keep changes
focused. Shared runtime lives in `shared/`; generated localized pages and
`extension/` are rebuilt with `npm run build`. Run `npm test` and `npm run check`.
For UI changes check 390px and 768px, light/dark themes and keyboard navigation.
Add complete dictionary keys for each language. Preserve upstream license files.
Never log or upload QR contents, passwords, clipboard contents or screenshots.
